## 一句话结论

> 把递归自我改进下沉到**研究工作流程**层面：两个互不共享代理/记忆/候选空间/研究状态的独立 LLM 研究系统（符号因子发现 + 可训练模型开发）各自在**密封沙箱**内闭环，用早期实验证据指导后续假设与候选——在 crypto 上因子信号联合 IC≈0.190，在美股上 per-stock IC=+0.0843、两腿成本后 held-out Sharpe 最高 +2.50，且 2021–2025 每年正收益。

## 问题背景

- 量化研究长周期、高人力成本，自动化程度低；LLM 可以生成假设，但**如何让"研究过程本身"递归自我改进**仍是开放问题。
- 更危险的失败模式：如果 agent 能修改数据路径/标签/评估器，或能读到它最终被打分的 test window，就会把 **leakage 当成成功先例**传播——这是 RSI 在金融里最致命的失败模式。
- 因子发现与模型开发若耦合在同一系统，会引入新的泄漏通道（论文 Section 6 明确指出）。

## 方法

1. **双系统隔离**：Part I 符号因子发现系统 + Part II 可训练模型开发系统；两者不共享 agents、memories、candidate spaces、research state。
2. **独立闭环**：每个系统只保留"已验证证据"，并用它指导后续提案，形成有界意义上的研究流程级 RSI。
3. **密封沙箱**：固定数据切分、特征与标签定义、评估器；模型只能通过**受限因子表达式**（DSL：rank/zscore/lag/rolling corr 等因果算子）或**配置 diff** 行动。
4. **Part I 因子系统**：manager 中介的多 agent 管线，发现并组合因子成综合信号。
5. **Part II 模型系统**：对混合时序架构做 config-driven 循环，把 per-stock IC 转化为阈值多空策略。

## 关键结果

| 实验 | 结果 |
|---|---|
| crypto 因子信号 | 联合信息系数 IC ≈ **0.190** |
| 美股 per-stock IC | **+0.0843** |
| 两腿成本后 held-out Sharpe | 最高 **+2.50** |
| 年度一致性 | 2021–2025 **每年正收益** |

## 与 RSI 知识库的关系

- 最贴近的"有界 RSI"工程范式：密封沙箱 = 把 P 区研究的 **self-rewrite 边界** 显式化为金融约束（不能碰数据/标签/评估器）。
- 与 [P01] RSI 综述中的"研究期 RSI"类别、[P04] LADDER 的"工作流即改进对象"思想一脉相承；是 **DGM/进化谱系（方向1 主范式）** 在金融侧的代表作。
- 论文自述"bounded sense"：不追求无限自我增强，而是限定在 research process 层面——呼应 RSI 知识库中"有界、可验证的自改进"基线。

## 解读与批判

- ✅ 首次系统性回答"RSI 在金融里如何不翻车"：隔离 + 密封 + 只保留已验证证据；held-out 口径严格（两腿成本、逐年为正）。
- ✅ 明确警告未密封 agent 的 leakage 传播问题，并给出工程对策（DSL 算子白名单、config diff）。
- ⚠️ 未使用 DGM 式谱系存档 / archive 多样性采样——热点文件指出"密封沙箱 + 进化谱系"仍是空白。
- ⚠️ Part I 与 Part II 完全隔离也意味着两部分经验无法互相复用；crypto 与美股各用单一 universe，外部有效性待扩展。
