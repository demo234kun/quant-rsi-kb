## 一句话结论

> 针对金融低信噪比 + 延迟标量奖励（P&L）下无约束 prompt 变异的 **credit assignment 崩溃**，引入 **SHARP**：把 agent 推理约束在一个有界、人类可读的显式 condition-action 规则 rubric 内，用**跨样本推理的归因 agent** 定位具体规则失效，做**原子化策略编辑**，并经严格 walk-forward 验证——在三个股票板块、四个 LLM backbone 下把紧凑模型（如 GPT-4o-mini）的表现平均提升 **10–20 个百分点**。

## 问题背景

- LLM 自动交易需要持续适应噪声、非平稳市场。
- 既有 self-improving agents 靠**无约束自由形式 prompt 优化**；但在低信噪比 + 延迟奖励（P&L）下，优化器**无法区分系统性逻辑缺陷与随机市场波动** → credit assignment 崩溃 → policy drift。
- 机构金融要求结构透明与可审计性。

## 方法

1. **符号化策略表示**：把 agent 推理约束进有界、人类可读的 condition-action 规则 rubric（显式规则集）。
2. **归因 agent**：次优交易出现时，用**跨样本（cross-sample）推理**隔离"哪条规则在哪个样本类型上失效"。
3. **原子化编辑（atomic policy edits）**：只改被归因的规则，不盲目重写策略。
4. **严格 walk-forward 验证**：每次编辑都要通过滚动前推验证才被接受（正则化）。

## 关键结果

| 实验 | 结果 |
|---|---|
| 板块覆盖 | 三个多样股票板块 |
| Backbone | 四个 LLM backbone |
| 紧凑模型提升 | 平均 **+10 至 +20 个百分点**（如 GPT-4o-mini） |
| 主要结论 | 通用初始 heuristics 被转化为稳健策略，同时保持结构透明与可审计 |

## 与 RSI 知识库的关系

- 直接回应 [P 区] 关于"自改进 agent 的 credit assignment 难"的讨论：用**结构化规则 + 归因**替代自由文本变异。
- "有界、可读、可审计"的 rubric = 有界 RSI 的又一实例（与 [Q01 AQuA] 的密封沙箱异曲同工：一个封数据，一个封策略形态）。
- 热点文件方向3 明确指出：**runs 规则+因果归因（哪条规则在哪个 regime 赚钱）** 是后续可做的创新点——SHARP 只做到规则级归因，未到 regime 级因果。

## 解读与批判

- ✅ 科学地解决金融 RSI 特有的 credit assignment 问题，而非简单堆 prompt。
- ✅ 归因 + 原子编辑 + walk-forward 验证三段式，工程上可审计、可回滚。
- ✅ 紧凑模型 +10–20pp 说明方法对资源受限场景友好。
- ⚠️ 论文自陈未考虑执行滑点与市场冲击（Section 5 局限）。
- ⚠️ Rubric 的初始形态仍由人提供，规则的表示能力上限约束了策略复杂度。
