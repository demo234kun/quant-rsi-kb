## 一句话结论

> 提出 **Adaptive-OPRO**：用**实时随机反馈**动态更新交易 agent 的指令（prompt），把"以输出为导向的提示优化"（OPRO）从静态改为适配——跨多个 LLM 家族与 regime 特定股票研究，Adaptive-OPRO 一致优于固定 prompt；而 **reflection-based 反馈不能提供系统性改善**——这个"反思无效、随机反馈有效"的负结果本身很有信息量。

## 问题背景

- LLM 金融决策要解决三个根本挑战：① 奖励**迟到且被市场噪声遮蔽**时如何调整指令；② 如何把异构信息流（行情/新闻/基本面）综合成连贯决策；③ 模型输出与**可执行市场动作**之间的鸿沟。
- 交易 agent 的滞后高维反馈使得"像 OPRO 那样按目标优化 prompt"难以直接落地。

## 方法

1. **统一多 Agent 框架**：整合市场、新闻、公司基本面三类结构化信息。
2. **order-aware 动作空间**：中心交易 agent 的每个输出对应**可执行订单**而非抽象信号（弥合"输出→动作"鸿沟）。
3. **Adaptive-OPRO**：在交易中实时吸收随机性反馈（stochastic feedback）动态适配 prompt，随轮次提升表现。
4. 与 reflection-based 反馈做对照实验（结果为负）。

## 关键结果

| 实验 | 结果 |
|---|---|
| Adaptive-OPRO vs 固定 prompt | 跨 regime 特定股票研究与多个 LLM 家族，**一致更优** |
| Reflection-based 反馈 | **未能提供系统性改善**（负结果） |
| 动作空间 | order-aware，输出直接映射可执行订单 |

## 与 RSI 知识库的关系

- 与 [P 区] OPRO 类"以输出为导向的提示优化"直接关联：ATLAS 把 OPRO 从"静态优化"升级为"运行时自适应"。
- 属于研究级/部署级 RSI 的轻量通道：不做权重更新、不进化代码，只随环境反馈改指令——与 [Q08 EvolveTrade]/[Q09 SHARP] 的"文本策略自进化"同族（Gödel Agent 路线）。
- 热点文件方向3 把它列为"动态指令适配"代表；其"反思无效"结论对 RSI 设计有警示价值（不是所有自反身反馈都有用）。

## 解读与批判

- ✅ 明确回答了一个方法学问题：**随机反馈 > 反思反馈**（对金融 RSI 的反馈设计有直接指导）。
- ✅ order-aware 动作空间把 agent 输出锁定到可执行订单，工程落地性强。
- ⚠️ 摘要层面未披露收益口径与改进幅度数值（需读正文）。
- ⚠️ 指令优化可能过拟合近期 regime；"提升随时间增长"需要更长周期的验证。
