## 一句话结论

> 把 LLM 当作**自适应认知 agent**，在代码级 alpha 表示上做迭代"精炼-变异-重组"（多阶段 prompt + 金融反馈），让探索同时具备逻辑一致性与创造性跳跃：在 3 个市场、5 个股票数据集上一致挖出预测精度、稳健性、泛化性都更优的 alpha——"进化 + 人类式认知搜索"范式的代表。

## 问题背景

- 高维、极低信噪比的金融数据上挖 alpha 是困难开放问题。
- 深度学习方法产生**不透明且脆弱**的模式；符号/公式方法产出**冗余且缺乏经济依据**的表达式。
- 两种范式的共性缺陷：都不能做"**宽广、结构化、类人**"的探索——同时平衡逻辑一致性与创造性跳跃。

## 方法

1. **代码级 alpha 表示**：候选以代码形式（程序级）表示，扩展搜索空间表达力。
2. **LLM 作为认知 agent**：多阶段 prompts + 金融反馈迭代改进、变异、重组候选。
3. **进化 + 推理协同**：进化搜索保证广度，LLM 推理保证逻辑一致性与经济可解释性（热点文件补充：7 层 agent 层级 + 多 agent 质量检查器）。
4. 在 5 个股票数据集（3 个市场）验证。

## 关键结果

| 实验 | 结果 |
|---|---|
| 数据集 | 3 个市场、5 个股票数据集 |
| 性能 | 一致的更优预测精度 / 稳健性 / 泛化性 |
| 搜索空间 | 显著扩大有效搜索空间 |
| 可解释性 | 产出经济可解释的 alpha |

## 与 RSI 知识库的关系

- 方向7/方向1 的交叉成员：代码级进化（Q18/Q19/Q20 族）+ 认知式搜索，同时挂靠 **OpenEvolve 移植**（README 分类速览将其归入 OpenEvolve/AlphaEvolve 移植）。
- 多 agent 质量检查器 ≈ 内置对进化产出的"批判层"——自改进系统需要第二意见。
- "进化保广度、LLM 保逻辑"的混合架构，回应了"纯进化无金融知识 / 纯 LLM 无搜索保障"的单一范式缺陷。

## 解读与批判

- ✅ 把"认知式探索"（创造性 + 一致性）显式化为多阶段 prompt 工程 + 进化操作，是范式融合的清晰尝试。
- ✅ 到 7 层 agent 层级体现工程成熟度（质量检查器等）。
- ⚠️ 摘要未报告具体数值（IC/收益），改进幅度的显著性需正文佐证。
- ⚠️ 没有 5 个数据集的退化/失败样例分析，进化后期拥挤问题未讨论。
